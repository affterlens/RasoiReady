# 🥬 RasoiReady 

**Farm Fresh, Kitchen Ready.** 
RasoiReady is an upcoming quick-commerce platform delivering pre-cut vegetables, boiled essentials, and hygienically cleaned seafood directly to doorsteps in Jalgaon, Maharashtra (425001).

## 🚀 About The Project
This repository holds the frontend landing page for RasoiReady. Our mission is to reduce kitchen prep-time for busy households while providing premium, farm-fresh quality. Backed by deep agricultural roots, we source the best produce and handle the cutting, boiling, and cleaning in a highly professional, sanitized environment.

### 📦 Product Categories
1. **Fresh Cut Vegetables:** Diced and sliced veggies, vacuum/hygienically sealed.
2. **Boiled Vegetables:** Pre-boiled essentials to save cooking time and fuel.
3. **Cleaned Seafood:** Ready-to-cook Crabs and Kolambi (Prawns), thoroughly cleaned and prepped.

## 🛠️ Built With
* HTML5
* CSS3 (Responsive Design)

## 🌐 Live Preview
This static page acts as our initial digital storefront, directing local customers to a WhatsApp ordering system while the full e-commerce backend (admin panel and live database) is developed.
